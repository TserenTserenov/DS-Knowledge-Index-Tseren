# Объекты внимания и рабочие продукты

## Объекты внимания (Objects of Attention)

Объекты, за состоянием которых следит организатор на каждом этапе.

| Объект | Описание | Отслеживаемые состояния |
|--------|----------|------------------------|
| **Мероприятие** | Центральный объект домена | Замысел → Планирование → Готовность → Проведение → Завершено |
| **Бюджет** | Финансовый план и факт | Draft → Approved → In Execution → Closed |
| **Программа** | Содержательный план | Concept → Draft → Confirmed → Finalized |
| **Площадка** | Место проведения | Shortlist → Viewed → Negotiating → Booked → Ready |
| **Участник** | Зарегистрированный / приглашённый | Invited → Registered → Confirmed → Attended |
| **Спикер** | Докладчик/ведущий | Identified → Invited → Confirmed → Briefed → Ready |
| **Подрядчик** | Внешний поставщик | Identified → RFP Sent → Offer Received → Contracted → Delivered |

## Рабочие продукты (Work Products)

Документы и артефакты, создаваемые в домене.

### Планирование

| Продукт | Описание | Формат |
|---------|----------|--------|
| **Event Brief** | Бриф мероприятия: цели, аудитория, формат, бюджет | Doc |
| **Мастер-план** | Полный план задач с ответственными и дедлайнами | Spreadsheet / PM-tool |
| **Бюджет** | Смета: статьи, плановые и фактические суммы | Spreadsheet |
| **Программа мероприятия** | Расписание сессий, спикеров, активностей | Doc / Spreadsheet |
| **Run-of-Show** | Поминутный сценарий дня проведения | Doc |

### Коммуникации

| Продукт | Описание | Формат |
|---------|----------|--------|
| **Приглашение участникам** | Текст/дизайн приглашения | Email / PDF |
| **Бриф для спикера** | Инструкция: формат, аудитория, технические требования | Doc |
| **Бриф для подрядчика** | ТЗ на услугу | Doc |
| **Программа для участников** | Публичная версия программы | PDF / Web |

### Проведение

| Продукт | Описание | Формат |
|---------|----------|--------|
| **Список участников** | Реестр зарегистрированных | Spreadsheet |
| **Чек-лист дня** | Задачи команды в день мероприятия | Checklist |

### Постанализ

| Продукт | Описание | Формат |
|---------|----------|--------|
| **Отчёт мероприятия** | Факт vs план: метрики, выводы | Doc |
| **NPS / Опрос участников** | Обратная связь | Form → Report |
| **Дебриф-встреча** | Протокол разбора с командой | Meeting Notes |
