# Bounded Context: Организация мероприятий

## Что входит в домен

- Замысел и концепция мероприятия
- Программа и контент (спикеры, темы, форматы)
- Производство: логистика, площадка, технический стек
- Маркетинг и набор участников
- Проведение (онлайн / офлайн / гибрид)
- Постпродакшн: записи, материалы, аналитика
- Монетизация: билеты, спонсорство, партнёрства

## Что не входит (соседние домены)

| Тема | Где она живёт |
|---|---|
| Разработка учебных программ | PACK-education |
| Платформенная инфраструктура | PACK-digital-platform |
| Контент-маркетинг и соцсети | DS-creator-development |
| Управление командой / HR | вне текущих Pack |

## Контекстные границы

```
[Замысел] → [Программа] → [Производство] → [Проведение] → [Постпродакшн]
                ↑                                               ↓
          PACK-education                               DS-creator-development
```

## Ключевые внешние зависимости

- Аудитория: студенты Aisystant, IT-специалисты, основатели стартапов
- Платформа: Aisystant (регистрация, трансляция, записи)
- Партнёры: спикеры, спонсоры, площадки
