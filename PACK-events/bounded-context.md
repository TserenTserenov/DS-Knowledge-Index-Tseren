# Bounded Context: Организация мероприятий

## Что входит в домен

- Разработка концепции и цели мероприятия
- Бюджетирование и финансовое планирование
- Выбор и бронирование площадки
- Работа с подрядчиками (кейтеринг, технический звук/свет, дизайн, транспорт)
- Формирование программы и управление спикерами/участниками
- Коммуникации и маркетинг мероприятия
- Логистика участников
- Проведение мероприятия (day-of management)
- Постанализ и отчётность

## Что НЕ входит (граница домена)

- Производство контента (входит в домен «Контент-маркетинг»)
- Долгосрочное управление сообществом (домен «Community management»)
- Финансовый учёт организации (домен «Финансы»)
- HR-процессы команды (домен «HR»)

## Язык домена (Ubiquitous Language)

| Термин | Определение |
|--------|-------------|
| Мероприятие / Ивент | Организованное событие с участниками, программой и площадкой |
| Организатор | Роль, несущая ответственность за результат мероприятия |
| Площадка (Venue) | Физическое или виртуальное пространство проведения |
| Участник | Человек, принимающий участие в мероприятии |
| Подрядчик | Внешний поставщик услуг для мероприятия |
| Программа | Структурированный план активностей мероприятия |
| Бриф | Документ с целями и параметрами мероприятия |
| Run-of-show | Детальный поминутный сценарий проведения |
| Дебриф | Постанализ мероприятия |

## Смежные домены

- **Маркетинг** — продвижение, регистрация участников
- **Финансы** — бюджет, оплата подрядчиков
- **Образование** — учебные мероприятия (воркшопы, курсы)
- **PR/Коммуникации** — медиапокрытие, пресс-релизы
