# Указатель методов: Организация мероприятий

| ID | Метод | Описание | Этап |
|----|-------|----------|------|
| OM-M-001 | [Планирование мероприятия](methods/event-planning.md) | Полный цикл от брифа до мастер-плана | Планирование |
| OM-M-002 | [Управление подрядчиками](methods/vendor-management.md) | RFP, выбор, контракт, приёмка | Планирование + Постанализ |

---

## Жизненный цикл мероприятия

```
Замысел → Планирование → Подготовка → Проведение → Постанализ
```

| Этап | Горизонт | Ключевые методы |
|------|----------|----------------|
| **Замысел** | T-N месяцев | Brief creation |
| **Планирование** | T-3м .. T-2нед | OM-M-001, OM-M-002, OM-M-006 |
| **Подготовка** | T-2нед .. T-1д | OM-M-003, OM-M-004 |
| **Проведение** | День T | OM-M-004 |
| **Постанализ** | T+1д .. T+2нед | OM-M-005 |
