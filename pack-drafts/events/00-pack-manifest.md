# Pack Manifest: Организация мероприятий

## Идентификатор

- **Pack ID**: `EM`
- **Версия**: 0.1.0
- **Статус**: Draft

## Область

**Название**: Организация мероприятий (Event Management)

**Описание**: Предметная область профессиональной организации мероприятий: концепция и форматы событий, работа с площадками и подрядчиками, программирование и сценирование, управление бюджетом, коммуникации с участниками и спикерами, логистика, риск-менеджмент, постмероприятийный анализ. Охватывает офлайн, онлайн и гибридные форматы.

## Scope

### В scope

- Концепция мероприятия: цель, формат, аудитория, ценностное предложение
- Жизненный цикл события: планирование → подготовка → проведение → постпродакшн
- Работа с площадкой: поиск, оценка, бронирование, логистика
- Программирование и сценирование: программа, run-of-show, фасилитация
- Бюджетирование: смета, контроль, согласование с заказчиком
- Управление подрядчиками: реестр, брифинг, контроль качества
- Коммуникации: с участниками, спикерами, партнёрами, командой
- Управление рисками: идентификация, митигация, реагирование
- Постмероприятийный анализ: метрики, отчётность, lessons learned
- Различения: мероприятие/проект, контент/программа, участник/гость/спикер
- Failure modes организаторов мероприятий
- SOTA: гибридные форматы, event-tech стек

### Вне scope

- Продажи билетов и CRM (отдельный downstream)
- Маркетинг и продвижение мероприятия (отдельный Pack или DS)
- Юридические контракты и NDA (downstream/legal)
- Разработка ивент-платформ (PACK-digital-platform)
- Контент самого мероприятия (доклады, программы, обучающие материалы)

## Entity Index

| ID | Name | Kind | Summary | Status |
|----|------|------|---------|--------|
| EM.D.001 | Мероприятие ≠ Проект | D | Мероприятие — одноразовое событие с жёсткой датой и публичным исходом; проект допускает перенос и итерации. Разная культура управления рисками и принятия решений | active |
| EM.D.002 | Контент ≠ Программа | D | Контент — что говорится и показывается; программа — структура, порядок, тайминг и переходы. Можно иметь отличный контент и плохую программу | active |
| EM.D.003 | Площадка ≠ Место проведения | D | Площадка — физический объект с характеристиками (вместимость, техоснащение, питание); место проведения — географическая и концептуальная позиция в восприятии аудитории | active |
| EM.D.004 | Участник ≠ Гость ≠ Спикер ≠ Партнёр | D | Четыре разных контракта: участник платит и потребляет, гость приглашён и VIP-обслуживается, спикер создаёт контент и требует speaker care, партнёр получает visibility и требует интеграции | active |
| EM.D.005 | Бюджет мероприятия ≠ Смета подрядчика | D | Бюджет — финансовая модель события (доходы + расходы + резерв); смета подрядчика — только часть расходной стороны. Путаница ведёт к перерасходу | active |
| EM.D.006 | Онлайн-формат ≠ Гибридный формат | D | Онлайн — всё происходит в цифре; гибрид — две аудитории (офлайн + онлайн) с разным опытом, требующие отдельного продюсирования. «Просто включить трансляцию» — не гибрид | active |
| EM.EVENT.001 | Конференция | EVENT | Формат события с докладами, сессиями, нетворкингом. Признаки: программный комитет, спикеры-эксперты, аудитория 50–2000+, 1–3 дня | active |
| EM.EVENT.002 | Корпоративное мероприятие | EVENT | Событие для сотрудников организации: тимбилдинг, стратегическая сессия, годовой праздник. Признаки: закрытая аудитория, заказчик = HR/CEO, KPI — вовлечённость | draft |
| EM.EVENT.003 | Публичное деловое мероприятие | EVENT | Форум, саммит, митап — открытое событие для профессионального сообщества. Признаки: внешние участники, PR-задача, медиа-присутствие | draft |
| EM.FM.001 | Scope Creep без пересмотра бюджета | FM | Заказчик добавляет элементы после утверждения концепции, не пересматривая бюджет. Организатор берёт доп. нагрузку, не компенсируя затраты — мероприятие уходит в минус | active |
| EM.FM.002 | Timeline Compression | FM | Сжатие сроков подготовки из-за поздних решений. Следствие: вынужденные переплаты подрядчикам за срочность, снижение качества, ошибки в логистике | active |
| EM.FM.003 | Stakeholder Misalignment | FM | Разные стейкхолдеры имеют несогласованные ожидания от мероприятия (CEO хочет брендинг, HR — вовлечённость, продажи — лиды). Организатор работает без единого briefа, пытаясь угодить всем | active |
| EM.FM.004 | Single Vendor Dependency | FM | Ключевой элемент мероприятия (звук, питание, трансляция) обеспечивает единственный подрядчик без резерва. При его сбое нет запасного плана | active |
| EM.M.001 | Event Concept Design | M | Метод разработки концепции мероприятия: цель → аудитория → формат → ценностное предложение → опыт участника. Результат: утверждённый Event Brief (EM.WP.001) | active |
| EM.M.002 | Venue Selection | M | Метод выбора площадки: требования → лонглист → шортлист → site visit → переговоры → бронирование. Критерии: вместимость, техоснащение, логистика, стоимость, атмосфера | active |
| EM.M.003 | Event Budget Planning | M | Метод построения бюджета мероприятия: доходная часть (билеты, партнёры, грант) + расходная (площадка, подрядчики, маркетинг, команда) + резерв 10–15%. Итерационное согласование с заказчиком | active |
| EM.M.004 | Programme Design | M | Метод проектирования программы: цели → дуги опыта участника → блоки (пленарные, параллельные, нетворкинг) → тайминг → run-of-show. Принцип энергетической кривой: открытие → кульминация → закрытие | active |
| EM.M.005 | Event Risk Management | M | Метод управления рисками: реестр рисков → вероятность × влияние → план митигации → contingency plan. Обязательные резервы: технический, кейтеринг, транспорт, спикеры | active |
| EM.M.006 | Post-Event Review | M | Метод постмероприятийного анализа: сбор данных (NPS, посещаемость, бюджет факт/план) → debrief команды → lessons learned → отчёт заказчику → обновление шаблонов | active |
| EM.ROLE.001 | Event Manager | ROLE | Управляет всем жизненным циклом мероприятия: от концепции до отчёта. Отвечает за бюджет, сроки, команду и удовлетворённость заказчика. Входная точка для заказчика | active |
| EM.ROLE.002 | Event Producer | ROLE | Отвечает за техническую реализацию и run-of-show: свет, звук, сцена, трансляция, тайминг. Работает в тесной связке с площадкой и техподрядчиками | draft |
| EM.ROLE.003 | MC / Ведущий | ROLE | Управляет вниманием зала, ведёт программу, обеспечивает переходы между блоками. Должен быть включён в репетицию и иметь run-of-show за 48ч до старта | active |
| EM.SC.001 | Мероприятие проведено без сбоев | SC | Программа выполнена по тайм-лайну ±10 мин, технических сбоев не было или они устранены незаметно для участников, все ключевые элементы реализованы | active |
| EM.SC.002 | Бюджет соблюдён | SC | Фактические расходы не превышают утверждённый бюджет более чем на 5% резервного буфера. Все отклонения согласованы с заказчиком заранее | active |

| EM.WP.001 | Event Brief | WP | Главный документ концепции: цель, аудитория, формат, дата/место, бюджет, KPI, заказчик. Утверждается до начала активной подготовки | active |
