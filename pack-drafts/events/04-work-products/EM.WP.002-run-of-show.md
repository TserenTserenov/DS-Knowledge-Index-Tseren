# EM.WP.002 · Run-of-Show — Сценарий дня X

## Назначение

Главный операционный документ на площадке. Пошаговый сценарий: время → блок → ответственный → техтребования → примечания. Синхронизируется с командой за 48 часов.

## Принципы

- **Один документ** — у всех одна версия (Google Sheets или Notion в реальном времени)
- **Каждая строка = действие** — не «открытие», а «14:00 — ведущий выходит на сцену»
- **Технические требования явно** — что включить, что выключить, чья ответственность
- **Буферы видны** — время перехода между блоками зафиксировано

## Цветовое кодирование (рекомендуется)

- 🟢 Зелёный — блок идёт по плану
- 🟡 Жёлтый — задержка до 5 мин, ситуация под контролем
- 🔴 Красный — требует оперативного решения
- ⬜ Серый — ещё не начался

## Правила выпуска

1. **-48ч**: черновик разослать всей команде, спикерам, MC
2. **-24ч**: внести правки по обратной связи, зафиксировать финальную версию
3. **-2ч**: распечатать для всей команды (бумажная копия — резерв при отказе связи)
4. **В день**: у каждого в телефоне / распечатка
