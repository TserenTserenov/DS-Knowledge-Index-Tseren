# [EV.ROLE.001] Роли мероприятия

## Организационная команда

| Роль | Ответственность | Ключевые рабочие продукты |
|------|----------------|--------------------------|
| **Event Director** | Общая концепция, бюджет, финальные решения | Концепция, бюджет, итоговый отчёт |
| **Program Director / Куратор** | Содержание, спикеры, программа | Программа, список спикеров, бриф спикера |
| **Operations Manager** | Логистика, площадка, вендоры | Operational checklist, тайминг дня |
| **Marketing Manager** | Продвижение, коммуникации, регистрация | Медиаплан, лендинг, email-цепочки |
| **Sponsor Manager** | Работа со спонсорами и партнёрами | Спонсорский пакет, соглашения |
| **Tech Lead** | Техническое обеспечение (звук, свет, стриминг) | Тех. райдер, схема оборудования |
| **Volunteer Coordinator** | Управление волонтёрской командой | Инструктаж волонтёров, расписание |

## Роли в зале / на площадке

| Роль | Ответственность |
|------|----------------|
| **MC / Ведущий** | Ведёт программу, управляет энергией зала |
| **Фасилитатор** | Организует групповые процессы, Q&A, воркшопы |
| **Спикер / Докладчик** | Готовит и представляет контент |
| **Модератор панели** | Ведёт дискуссию, балансирует голоса |
| **Волонтёр** | Регистрация, навигация, помощь участникам |

## Внешние участники

| Роль | Отношения |
|------|-----------|
| **Участник (Attendee)** | Основной получатель ценности |
| **Спонсор** | Вкладывает ресурсы за видимость |
| **Партнёр** | Взаимовыгодное участие |
| **Медиапартнёр** | Освещает мероприятие |
| **Вендор / Подрядчик** | Предоставляет услуги (кейтеринг, фото, площадка) |

## Матрица RACI (упрощённая)

| Задача | Event Director | Ops Manager | Marketing | Program Director |
|--------|:-:|:-:|:-:|:-:|
| Концепция мероприятия | **R** | C | C | A |
| Выбор площадки | A | **R** | — | C |
| Программа и спикеры | A | C | C | **R** |
| Продвижение | A | C | **R** | C |
| Бюджет | **R** | A | C | C |
| День X — операции | A | **R** | C | C |
| Пост-анализ | **R** | A | A | A |

> R = Responsible, A = Accountable, C = Consulted
