# [EV.M.001] Разработка концепции мероприятия

## Зачем

Концепция — фундамент. Без неё программа, маркетинг и логистика не имеют единого стержня. Большинство провальных мероприятий начинались без проработанной концепции.

## Ключевые вопросы концепции

| Вопрос | Что определяет |
|--------|----------------|
| Зачем? (Why) | Цель мероприятия, измеримый результат |
| Для кого? (Who) | Целевая аудитория, её боли и желания |
| Что? (What) | Ценностное предложение — что участник получит |
| Как? (How) | Формат: конференция, воркшоп, митап, ретрит |
| Когда/Где? | Дата, площадка, масштаб |
| Почему мы? | Уникальность организатора и контента |

## Шаги метода

1. **Определить цель** — сформулируй 1 предложение: «По итогам мероприятия участники [действие] для того чтобы [результат]»
2. **Описать аудиторию** — Jobs-to-be-Done: что хочет сделать/достичь участник, приходя на мероприятие
3. **Сформулировать ценностное предложение** — что уникального участник получит здесь и нигде больше
4. **Выбрать формат** — исходя из цели и аудитории (не наоборот)
5. **Определить success metrics** — как поймём, что мероприятие удалось (NPS, количество контактов, сделки, обучение и т.д.)
6. **Создать одностраничную концепцию** — документ для команды, спонсоров и партнёров

## Одностраничная концепция (шаблон)

```
НАЗВАНИЕ МЕРОПРИЯТИЯ
Слоган / подзаголовок

ЦЕЛЬ: [1 предложение]
АУДИТОРИЯ: [портрет участника]
ФОРМАТ: [тип, продолжительность]
ДАТА/МЕСТО: [...]
ОЖИДАЕМОЕ КОЛ-ВО УЧАСТНИКОВ: [...]

ЦЕННОСТНОЕ ПРЕДЛОЖЕНИЕ:
- Для участника: [...]
- Для спонсора: [...]
- Для спикера: [...]

КЛЮЧЕВЫЕ ТЕМЫ / ТРЕКИ:
1. [...]
2. [...]

МЕТРИКИ УСПЕХА:
- [...]
```
