# [EV.M.009] Управление бюджетом мероприятия

## Структура доходов

| Статья | Примеры |
|--------|---------|
| Билеты | Early bird, regular, VIP, групповые |
| Спонсорство | Gold/Silver/Bronze пакеты |
| Партнёрские взносы | Площадка, сервисы in-kind |
| Запись / онлайн-доступ | Продажа записей после |
| Мерч | Брендированные товары |
| Гранты / субсидии | Для образовательных мероприятий |

## Структура расходов

| Категория | Типичная доля |
|-----------|--------------|
| Площадка | 20–35% |
| Питание / кейтеринг | 15–25% |
| Технологии (звук, свет, стриминг) | 10–20% |
| Маркетинг и продвижение | 10–15% |
| Гонорары спикеров | 5–20% |
| Транспорт / логистика | 5–10% |
| Материалы (бейджи, печать) | 3–7% |
| Непредвиденные расходы | ≥10% резерв |

## Финансовая модель (шаблон)

```
БЮДЖЕТ: [Название мероприятия]

ДОХОДЫ:
  Билеты:        ___ чел × ___ руб = ___
  Спонсорство:                      = ___
  Прочее:                           = ___
  ИТОГО ДОХОДЫ:                     = ___

РАСХОДЫ:
  Площадка:                         = ___
  Кейтеринг:                        = ___
  Технологии:                       = ___
  Маркетинг:                        = ___
  Спикеры:                          = ___
  Резерв (10%):                     = ___
  ИТОГО РАСХОДЫ:                    = ___

ПРИБЫЛЬ/УБЫТОК:                     = ___
ТОЧКА БЕЗУБЫТОЧНОСТИ: ___ билетов
```

## Ключевые метрики

| Метрика | Формула |
|---------|---------|
| Стоимость привлечения участника | Расходы на маркетинг / кол-во участников |
| Revenue per attendee | Общий доход / кол-во участников |
| Доля спонсорского дохода | Спонсорство / Общий доход × 100% |
| Маржинальность | (Доходы − Расходы) / Доходы × 100% |
