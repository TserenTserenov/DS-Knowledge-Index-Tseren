# [EV.M.007] Операционная логистика

## Runsheet (тайминг дня)

Главный документ дня. Должен быть у каждого члена команды.

```
RUNSHEET: [Название] — [Дата]
Ответственный: [Ops Manager]

ВРЕМЯ    | ДЕЙСТВИЕ                          | ОТВЕТСТВЕННЫЙ | СТАТУС
---------|-----------------------------------|---------------|-------
07:00    | Заезд команды на площадку         | Ops Manager   | □
07:30    | Проверка оборудования (звук/свет) | Tech Lead     | □
08:00    | Инструктаж волонтёров             | Vol. Coord.   | □
08:30    | Открытие регистрации              | Рег. стол     | □
09:00    | Открытие дверей                   | Все           | □
09:30    | Начало программы                  | MC            | □
...
18:00    | Завершение, фото                  | MC            | □
18:30    | Демонтаж и уборка                 | Команда       | □
19:30    | Команда покидает площадку         | Ops Manager   | □
```

## День X — зоны ответственности

| Зона | Ответственный | Задачи |
|------|--------------|--------|
| Вход / регистрация | Волонтёры | Бейджи, check-in, навигация |
| Сцена / зал | MC + Tech Lead | Тайминг, звук, смена слайдов |
| Нетворкинг-зона | Фасилитатор | Активация общения |
| Спонсорская зона | Sponsor Manager | Стенды, комфорт партнёров |
| Онлайн-трансляция | Tech Lead | Стрим, чат, Q&A онлайн |
| Питание | Ops Manager | Кейтеринг по расписанию |
| Связь с командой | Ops Manager | Общий чат, рации |

## Contingency план (типичные сбои)

| Сбой | Действие |
|------|---------|
| Спикер опаздывает | Продлить кофе-паузу / переставить блоки |
| Нет звука | Переключить на резервный микрофон, вызвать техника |
| Отключили интернет | Перейти на мобильный роутер (иметь запасной) |
| Меньше участников, чем ожидалось | Пересадить всех ближе к сцене, не показывать пустоту |
| Больше участников | Добавить стулья, открыть резервный зал |
| Спикер отменился | Иметь 1–2 «запасных» доклада / удлинить дискуссию |
