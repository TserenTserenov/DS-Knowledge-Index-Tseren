# [EV.M.010] Пост-событийный анализ

## Зачем

Каждое мероприятие — это эксперимент. Без структурированного дебрифа команда не учится, а повторяет ошибки. Хороший пост-анализ делает следующее мероприятие лучше на 30–50%.

## Временной план после мероприятия

| Срок | Действие |
|------|---------|
| В день | Краткий дебриф команды (30 мин стоя) — горячие впечатления |
| +24 часа | Отправить thank-you письма участникам + анкету обратной связи |
| +48 часов | Опубликовать фото/видео материалы |
| +1 неделя | Подвести финансовые итоги, собрать метрики |
| +2 недели | Полный ретроспективный документ |

## Метрики для анализа

### Количественные
| Метрика | Источник |
|---------|---------|
| Кол-во зарегистрировавшихся vs. пришедших | Регистрация |
| Доходы vs. план | Бюджет |
| NPS участников | Анкета |
| Средняя оценка программы (1–10) | Анкета |
| Кол-во новых контактов (если нетворкинг) | CRM / app |
| Охват в соцсетях | Аналитика |

### Качественные
- Что участники хвалили?
- Что критиковали?
- Что хотели бы видеть в следующий раз?
- Какие неожиданные моменты произошли?

## Шаблон анкеты участника

```
1. Как вы оцениваете мероприятие в целом? (1–10)
2. Какой доклад/сессия вам понравились больше всего?
3. Что можно было сделать лучше?
4. Порекомендовали бы вы следующее мероприятие коллегам? (NPS: 1–10)
5. Планируете ли вы прийти в следующий раз?
6. Ваши предложения по темам/форматам:
```
