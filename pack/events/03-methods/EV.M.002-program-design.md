# [EV.M.002] Программный дизайн

## Принципы

- **Энергетическая дуга**: начало — возбуждение, середина — глубина, финал — вдохновение/действие
- **Разнообразие форматов**: не более 3 докладов подряд без интерактива
- **Время на переходы**: закладывай +15 мин буфер на каждые 2 часа
- **Кульминационный момент**: каждая программа нуждается в «wow-моменте»

## Форматы активностей

| Формат | Продолжительность | Цель |
|--------|------------------|------|
| Keynote | 20–45 мин | Вдохновение, задать тон |
| Доклад | 15–30 мин | Передача знаний |
| Панельная дискуссия | 45–60 мин | Сравнение точек зрения |
| Воркшоп | 60–120 мин | Практика, навык |
| Q&A | 10–20 мин | Уточнение, диалог |
| Нетворкинг-сессия | 30–60 мин | Связи |
| Перерыв | 15–30 мин | Восстановление |
| Круглый стол | 60–90 мин | Совместное мышление |

## Структура программного документа

```
ПРОГРАММА: [Название мероприятия]
Дата: / Место:

09:00 — Регистрация и нетворкинг (30 мин)
09:30 — Открытие. Организатор. (15 мин)
09:45 — Keynote: [Тема] — [Спикер] (40 мин)
10:25 — Q&A (10 мин)
10:35 — Кофе-пауза (20 мин)
...
```

## Чеклист программного дизайна

- [ ] Каждый блок решает конкретную задачу (не просто «заполнить время»)
- [ ] Есть баланс докладов и интерактива
- [ ] Пики энергии расставлены стратегически (открытие, после обеда, финал)
- [ ] Каждый спикер получил бриф с ожиданиями
- [ ] Есть резервный план для опоздания / отмены спикера
- [ ] Финальный call-to-action понятен участникам
