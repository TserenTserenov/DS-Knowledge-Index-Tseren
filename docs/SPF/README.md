## Иерархия

```
FPF (первые принципы)  →  универсальные различения
       ↓
SPF (вторые принципы)  →  форма и процесс для Pack
       ↓
Pack (паспорт области) →  формализованное знание домена
       ↓
Downstream             →  курсы, боты, гайды
```
