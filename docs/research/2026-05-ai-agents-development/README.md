# Исследование: ИИ-агенты в системе личного развития

## Контекст

Это аналитическое исследование разбирает, что такое ИИ-агент в контексте личного развития, как он соотносится с человеком и с интеллектуальной рабочей средой (IWE), и что должен освоить человек, чтобы не просто пользоваться ИИ, а развиваться через работу с ним.

Материал написан как самостоятельный лонгрид (источник правды). Из него потом будут делаться адаптации в разные каналы: клуб, Facebook, LinkedIn, Telegram, Habr, Дзен. Каждая адаптация подсветит свою сторону: личное развитие, карьеру, архитектуру, провокацию.

## Основные оси анализа

1. **LLM, агент, исполнитель** — что в чём, границы понятий
2. **Problem → Task** — главный навык эпохи ИИ
3. **Роль и метод** — глубина обучения агента
4. **Пользовательский слой** — проблема, ресурсы, риск
5. **MCP** — инфраструктура контекста
6. **IWE vs ИИ-агент** — два разных слоя
7. **Два уровня деятельности** — пользователь vs разработчик
8. **Траектория развития** — где это входит в программу ЛР
