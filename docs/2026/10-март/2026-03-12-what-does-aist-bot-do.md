# Что делает @aist_me_bot в составе IWE

На днях Даниил задал хороший вопрос: «А что aist_bot должен делать в составе IWE? У меня он только заметки принимает. Мне проще своего сделать — но хочу понять задумку.»

Вопрос точный, и ответ будет полезен всем, кто начинает работать с платформой.

---

## Бот — один из интерфейсов, не центр

@aist_me_bot — платформенный сервис, общий для всех. Не нужно разворачивать свой — достаточно написать `/start`.

Главная идея IWE: бот — один из интерфейсов платформы. Он всегда рядом в Telegram, но не является центром системы. Центр — экзокортекс (CLAUDE.md + memory/) и агенты (Стратег, Экстрактор). Бот, Claude Code, веб-приложение — разные окна в одну среду.

## Что бот делает сейчас

**Марафон** — 14-дневная программа по входу в системное саморазвитие. Уроки приходят по расписанию, сложность адаптируется, бот напоминает если пропустил.

**Лента** — гибкий режим: выбираешь темы, получаешь ежедневные дайджесты, фиксируешь инсайты. Подходит тем, кто хочет учиться в своём темпе.

**Консультации** — задаёшь вопрос, бот отвечает с доступом к базе ~5300 документов по системному мышлению и саморазвитию.

**Заметки** — быстрые мысли в течение дня (точка + текст). Заметки сохраняются в стратегическое репо, и потом их обрабатывает Стратег.

**Планы** — дневной и недельный план, итоги вчерашнего дня, inbox triage. Всё это через интеграцию с GitHub strategy-репо. Планы можно видеть прямо в боте с телефона.

**Прогресс** — streak активных дней, уровень сложности, пройденные темы.

**Цифровой двойник** — сейчас подключаем ЦД через Ory ко всем ресурсам. Через бота можно будет видеть свой профиль развития.

**Интеграции** — GitHub, WakaTime, цифровой двойник.

## Нужен ли свой бот?

Зависит от цели:

- Если хочешь **пользоваться** марафоном, лентой, консультациями — @aist_me_bot уже работает, свой не нужен.
- Если хочешь **Стратега с планами** — это работает через IWE-шаблон (экзокортекс + Claude Code). Бот потом подтягивает результат из стратегического репо.
- Если хочешь **разрабатывать свою платформу** — тогда свой бот имеет смысл, но это другая задача.

Бот — интерфейс для просмотра с телефона. Вся тяжёлая работа происходит в Claude Code и агентах.
