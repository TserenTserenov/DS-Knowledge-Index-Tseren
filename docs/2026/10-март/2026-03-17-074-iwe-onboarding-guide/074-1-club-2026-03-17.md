# IWE для новичков: твоя интеллектуальная рабочая среда

Когда я впервые начал серьёзно работать с ИИ-ассистентами, у меня было стойкое ощущение, что что-то не так. Ответы хорошие, но каждый раз начинаешь с чистого листа. Объясняешь контекст заново. Через три дня ИИ не помнит, что ты решил в прошлый раз. Полезный инструмент, но не партнёр.

Тогда я начал строить то, что сейчас называю IWE — Intellectual Work Environment, интеллектуальная рабочая среда.

## Чем среда отличается от инструмента

Инструмент решает задачу. Молоток забивает гвоздь. ChatGPT отвечает на вопрос. Среда формирует способ работы. Она не делает одно действие — она определяет, как ты думаешь, планируешь, фиксируешь знания и взаимодействуешь с ИИ каждый день.

Хорошая аналогия — операционная система. macOS не «делает» ничего конкретного, но объединяет файлы, приложения, терминал в единое рабочее пространство. IWE делает то же самое для интеллектуальной работы: объединяет ИИ-ассистента, базы знаний, протоколы работы и инструменты в одну среду.

Ключевое следствие: среда растёт с тобой. Чем больше ты в ней работаешь, тем больше она знает о тебе — твоих целях, решениях, принципах, проектах. ИИ не начинает с нуля каждый раз. Он начинает с того места, где ты остановился.

## Из чего состоит IWE

Есть несколько частей, которые работают вместе.

**Экзокортекс** — это набор файлов, которые ИИ-ассистент читает при каждой сессии. Там хранятся твои принципы работы, текущие задачи, решения, которые ты принял, и контекст проектов. По сути — вторая память. Ты заканчиваешь работу, записываешь итоги. На следующий день ИИ точно знает, на чём ты остановился.

**Pack** — база знаний по твоей предметной области. Если ты изучаешь системное мышление или маркетинг, или управление продуктом — твои различения, принципы, выводы из опыта складываются в структурированную библиотеку. ИИ использует её в работе. Это не папка с заметками, а формализованное доменное знание.

**Claude Code** — ИИ-ассистент, который работает прямо в VS Code или в терминале. Он читает твой экзокортекс, знает твои проекты, помнит контекст. Ты общаешься на обычном русском языке.

**Протоколы ОРЗ** — простой ритм: Открытие, Работа, Закрытие. Открываешь день — ИИ показывает, что запланировано и на чём остановился вчера. Работаешь — фиксируешь знания в нужных местах по ходу. Закрываешь — итоги записаны, контекст обновлён. Ничего не теряется.

Ещё есть бот @aist_me_bot для Telegram — когда не за компьютером, можно получить ответ на вопрос из своей базы знаний или проверить задачи.

## Это не для программистов?

Нет, не только. Я понимаю, что GitHub, терминал, командная строка — с виду пугают. Но в работе с IWE ты не пишешь код. Ты пишешь тексты, планы, заметки — в обычных markdown-файлах. GitHub здесь как Google Drive, только с историей изменений. Терминал — это окно, в которое ты вводишь команды, а Claude Code сам подсказывает, что вводить.

Установка занимает около получаса: поставить Claude Code, создать аккаунт на GitHub, запустить один скрипт настройки. После этого общение — на русском языке.

Нужен компьютер (Mac, Linux или Windows с WSL) и подписка Claude Pro ($20/мес) или Claude Max ($100/мес для интенсивной работы). GitHub и VS Code — бесплатно.

## Про экзоскелет

Один вопрос, который возникает часто: «ИИ сделает всё за меня?»

Нет, и это не баг, а принцип проектирования. IWE строится как экзоскелет, не как протез. Протез заменяет способность. Экзоскелет усиливает. Разница в том, что после работы в экзоскелете ты становишься сильнее. После работы с протезом — зависимее.

На практике это значит: ИИ берёт на себя рутину — поиск файла, восстановление контекста, структурирование заметок. Но решения, выводы, направление — остаются за тобой. Твоё мышление не заменяется, а усиливается.

## С чего начать

Первый шаг — установка. Шаблон IWE лежит на GitHub: [FMT-exocortex-template](https://github.com/TserenTserenov/FMT-exocortex-template). Там же пошаговый гид ([SETUP-GUIDE.md](https://github.com/TserenTserenov/FMT-exocortex-template/blob/main/docs/SETUP-GUIDE.md)) и путь освоения ([LEARNING-PATH.md](https://github.com/TserenTserenov/FMT-exocortex-template/blob/main/docs/LEARNING-PATH.md)).

Если уже есть Claude Code — можно просто написать «помоги мне установить IWE», он проведёт через каждый шаг.

Первую неделю советую просто войти в ритм ОРЗ: открыл день, поработал, закрыл. Не нужно сразу разбираться во всех частях системы. Со временем будет понятно, что куда добавить.
