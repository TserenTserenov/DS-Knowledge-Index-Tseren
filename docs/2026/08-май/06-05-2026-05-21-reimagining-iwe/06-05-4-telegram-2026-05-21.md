# Переосмысляя IWE: от набора инструментов к дистрибутиву

Два года я объяснял IWE по-разному: то набор скриптов, то методология, то экзоскелет. Все ответы верные, ни один не точный.

На этой неделе наконец нашёл одно слово.

🔑 IWE — это дистрибутив. Как Ubuntu на ядре Linux.

Claude — ядро. Claude Code, бот, VS Code — интерфейсы. IWE — набор решений о том, как жить с этим ядром: как открывать и закрывать рабочую сессию, как сохранять память между разговорами, какие протоколы для стандартных ситуаций, как хранить доменные знания. Именно это делает систему системой, а не набором скриптов.

В новом посте разобрал это через таблицу из 8 слоёв — от базовой модели Anthropic до личного экзоскелета. И честно написал, где сегодня IWE ещё не соответствует этой схеме.

🧩 Весь мировой тренд агентных систем движется к разделению Runtime и Application — тот же паттерн, что произошёл с Linux в 90-х.
