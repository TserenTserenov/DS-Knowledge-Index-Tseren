# Что на самом деле продолжается, когда я открываю Claude Code с телефона

Открыл Claude на телефоне, увидел «Remote Control активен» — и понял, что не знаю, что именно это продолжает: ту же сессию с моей памятью и всеми репозиториями, или что-то новое с чистого листа.

Разобрался: это два разных продукта. Remote Control — зеркало живой сессии на компьютере (та же память, все репозитории, но нужен Max и включённый компьютер). Claude Code on the web (claude.ai/code) — отдельная облачная песочница без памяти, с одним репозиторием за раз, зато с обычного Pro и без компьютера вообще.

Полный разбор — с архитектурой, командами и тем, как я настроил компьютер, чтобы сессия не рвалась при закрытой крышке: [в клубе](41-08-1-club-2026-08-28.md).
