## Правило приоритизации

🔴 Критический = прямая связь с R1 (первая когорта, пилоты) или R3 (семинары, продвижение W21)
🟡 Средний = связь с S4 (видимость), S9 (ускорение), R4 (инвесторы)
🟢 Низкий = концептуальные, вечные темы, технические (можно в любой момент)

## Метод актуализации

Для каждого поста:
1. Прочитать текст + проверить актуальность фактов (ссылки, цены, названия)
2. Обновить зачин (если начинается с «В предыдущем посте» → сделать независимым)
3. Добавить контекст W19 где уместно (пилот, когорта)
4. Проверить по эталону голоса (CLAUDE.md § 9)
5. Сменить `status: draft` → `status: готово`
6. Обновить `date` на текущую
