## Личные репозитории (у каждого пользователя — свои)

Помимо платформенных, у каждого пользователя IWE есть собственные репозитории. Они не входят в общий Knowledge MCP — к ним доступ только у владельца через **Personal Knowledge MCP** (`personal-knowledge-mcp`).

Примеры личных репозиториев:

| Репозиторий | Что содержит |
|-------------|-------------|
| **DS-my-strategy** | Личное стратегирование — WeekPlan, DayPlan, результаты, рефлексия |
| **DS-Knowledge-Index-Tseren** | Персональный индекс знаний — заметки, посты, публикации |
| **DS-creator-development** | Персональное руководство по развитию — трек роста |
| **DS-autonomous-agents** | Эксперименты с агентами — код и заметки |

У меня, например, в личном MCP проиндексировано ещё ~3 100 документов поверх платформенных.

## Как это будет работать

Сейчас Knowledge MCP настраивается вручную — нужно прописать endpoint в конфиге Claude Code. Мы это уберём.

Планируемая схема:
1. **Платформенный Knowledge MCP** — подключается автоматически при активации IWE. Один endpoint, все платформенные репозитории. Пользователь ничего не настраивает.
2. **Personal Knowledge MCP** — автоматически индексирует личные репозитории пользователя (после OAuth через GitHub). Доступ изолирован по `user_id` — никто не видит чужие данные.
3. **Knowledge Gateway** — единая точка входа, которая объединяет оба MCP. Claude обращается к одному адресу и получает и платформенное знание, и личное.

Пользователю не нужно знать про MCP, endpoints или конфиги. Подключил GitHub — работает.

Все платформенные репозитории открыты — можно форкнуть, изучить, предложить изменения. Личные остаются приватными и под полным контролем владельца.
