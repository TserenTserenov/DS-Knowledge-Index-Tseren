# Открытые репозитории IWE и Knowledge MCP: полный список

Одна из вещей, которую я считаю принципиальной: знаниевая инфраструктура IWE — открытая. Не «open-core с платной версией», а именно открытая: форкни, прочитай, разберись, как устроено.

Сегодня публикую полный список репозиториев, которые входят в платформенный **Knowledge MCP** (`knowledge-mcp`) — сервис, через который ИИ-ассистент получает доступ к методологии интеллектуальной работы (МИМ). Все материалы МИМ доступны каждому пользователю бесплатно — достаточно присоединить IWE, и ассистент сразу знает методологию.

## Личные репозитории (у каждого пользователя — свои)

Помимо платформенного знания, у каждого пользователя IWE формируются собственные репозитории — личная база знаний. Они не входят в общий `knowledge-mcp`, к ним доступ только у владельца через **Personal Knowledge MCP** (`personal-knowledge-mcp`).

Примеры личных репозиториев (на моём примере):

| Репозиторий | Что содержит |
|-------------|-------------|
| **DS-my-strategy** | Личное стратегирование — WeekPlan, DayPlan, результаты, рефлексия |
| **DS-Knowledge-Index-Tseren** | Персональный индекс знаний — заметки, посты, публикации |
| **DS-creator-development** | Персональное руководство по развитию — трек роста, персональное задание на каждый день |
| **DS-autonomous-agents** | Эксперименты с агентами — код и заметки |

У меня в личном MCP проиндексировано ещё ~3 100 документов поверх платформенных.

## Как это работает сейчас и что изменится

Доступ к материалам МИМ через платформенный `knowledge-mcp` уже работает и предоставляется бесплатно каждому пользователю. Пользователю достаточно присоединить IWE — и ассистент сразу знает методологию, терминологию, практики. Никакой дополнительной настройки.

А вот с личной базой знаний до сих пор было сложнее. Чтобы ассистент видел твои собственные репозитории — стратегию, заметки, персональное руководство — пользователю приходилось самостоятельно настраивать Personal Knowledge MCP: создавать индекс, прописывать endpoint, поддерживать синхронизацию. Для технаря — терпимо. Для остальных — барьер.

Мы это убираем. Вместо ручной настройки появится **Knowledge Gateway** — единая точка входа, за которой стоят три MCP-сервиса:

1. **`knowledge-mcp`** — платформенное знание (МИМ, принципы, паспорта предметных областей). Общее для всех, без авторизации на чтение.
2. **`personal-knowledge-mcp`** — личная база знаний пользователя. Репозитории, которые пользователь выбрал для индексации. Изоляция по `user_id` — никто не видит чужие данные.
3. **`digital-twin-mcp`** — цифровой двойник пользователя. Прогресс, профиль, активные области развития.

Пользователю нужно подключить один адрес — Knowledge Gateway. Всё остальное платформа делает сама: индексирует репозитории, изолирует данные, обновляет при изменениях. Один раз подключил — ассистент знает и методологию, и тебя.

Knowledge Gateway — это стандартный MCP-сервер. Его можно подключить к любой LLM, которая поддерживает MCP через connect: Claude Code, Claude Desktop, Cursor, Windsurf, ChatGPT и другие. Не привязан к одному провайдеру — работает там, где работаешь ты.
