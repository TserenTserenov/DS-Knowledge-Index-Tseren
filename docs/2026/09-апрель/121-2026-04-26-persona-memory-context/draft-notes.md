# Заметки к посту 121: Не «второй мозг», а три слоя

## Назначение

Развитие линии поста 110 («три слоя ИИ-агентов: модель / роль / контекст») — но **с другой стороны стола**: не три слоя ИИ-системы, а три слоя **моих собственных данных**, которые с этой системой работают.

Триггер — обновление урока ss-lesson-08 Блок 5 (26 апр): метафора «второй мозг» заменена на слоистую модель Персона/Память/Контекст. Эта же модель востребована в клубе — обсуждения «у меня всё в Notion» / «я не понимаю, что у Aisystant обо мне» / «как ИИ помнит контекст» — на самом деле про эти три слоя без явных имён.

## Ядро (что хочется сказать)

Когда говорят «у меня есть второй мозг» — теряется главное: **где моё, а где системы**. Метафора плоская. Точнее — три слоя по двум осям: **кто пишет** (writer) + **кому принадлежит** (owner).

1. **Персона** — пишу я сам, владею я. Заметки, ценности, цели.
2. **Память** — пишет система автоматически. Носитель — где угодно: платформа, локальная БД, vector store, биологическая память. Не «облако» против «локального», а «писатель — не я».
3. **Контекст** — собирает агент в runtime под один LLM-вызов. Исчезает с концом сессии.

Тест границы: «Что пропадёт, если удалю X?» — три разных носителя, три разных ответа.

## Уточнение, которое часто теряется

**Память ≠ платформа.** Многие думают: Персона = моё локально, Память = облачный сервис. Это неправильное разделение.

Память может жить:
- На платформе (Aisystant, Notion-клон)
- В локальной БД на ноутбуке
- В vector store моей собственной системы
- В памяти самого ИИ-агента (Claude Memory, ChatGPT memory)
- В биологической памяти человека (когда мы говорим про команду или сообщество как систему)

Главное — **писатель не я в момент действия**, а какой-то автоматический процесс системы.

## Парная иллюстрация — Экзоскелет ≠ Автопилот

Слоистая модель отвечает «где». Различение «экзоскелет vs автопилот» — «в каком режиме я этим всем пользуюсь». Без второго различения первое превращается в учёт без смысла.

Тест: «Могу объяснить решение **без** фразы "ИИ подсказал"?» — Да = экзоскелет. Нет = автопилот.

## Структура поста (черновик)

1. Зацепка: «у меня есть второй мозг» — что это значит на практике, и почему фраза прячет главное.
2. Парадокс: спросите трёх человек, что у них в этом «втором мозге» — у одного Notion, у другого ChatGPT-memory, у третьего git-репо. Это разные слои с разными свойствами.
3. Различение по двум осям: writer + owner.
4. Три слоя — по матрице (схема illustration.md).
5. Уточнение: Память не привязана к платформе.
6. Парная рамка: экзоскелет ≠ автопилот (D.046).
7. Тест для читателя: «что пропадёт, если удалю X?» — на каждый слой по примеру.
8. CTA для клуба: разобрать на встрече, сделать аудит своих трёх слоёв.

## Варианты названия (3-5 на выбор пользователю)

1. **«Не "второй мозг", а три слоя: Персона / Память / Контекст»** — прямое опровержение метафоры, понятно сразу.
2. **«Где моё, а где системы: три слоя экзокортекса»** — акцент на главном вопросе, который прячет «второй мозг».
3. **«Что у вас во "втором мозге"? Спросите по-другому»** — провокационное, через CTA.
4. **«Память — не равно платформа: ловушка плоской метафоры»** — акцент на главном уточнении.
5. **«Кто пишет ваш экзокортекс: вы, система или агент?»** — три ответа = три слоя, через writer.

Рекомендую 1 или 2 — самые точные и наименее кликбейтные. (3) и (5) — для facebook/linkedin адаптаций.
