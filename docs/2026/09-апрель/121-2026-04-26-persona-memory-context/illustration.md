# Иллюстрация: Три слоя экзокортекса

> Критерий разделения = **кто пишет** (writer) + **кому принадлежит** (owner). Не «ближе/дальше к мозгу», не «свежее/старее», не «семантическое/эпизодическое». Только эти две оси.

## Основная схема

```mermaid
flowchart TB
    subgraph Persona["🟢 ПЕРСОНА — мой слой"]
        direction TB
        P_writer["<b>Writer:</b> я сам<br/>(или агент с моим согласием)"]
        P_owner["<b>Owner:</b> моё<br/>(Git-репо, личные заметки)"]
        P_ex["Заметки, чек-листы,<br/>ценности, цели, Личный устав"]
    end

    subgraph Memory["🟡 ПАМЯТЬ — слой системы"]
        direction TB
        M_writer["<b>Writer:</b> система<br/>(не я в момент действия)"]
        M_owner["<b>Owner:</b> носитель системы<br/>(может быть где угодно)"]
        M_ex["События моих действий,<br/>агрегаты, история взаимодействия,<br/>расчёты-индикаторы"]
        M_note["💡 Носителем может быть:<br/>платформа, локальная БД,<br/>vector store, память ИИ-агента,<br/>биологическая память человека.<br/><b>НЕ привязано к платформе.</b>"]
    end

    subgraph Context["🔵 КОНТЕКСТ — слой runtime"]
        direction TB
        C_writer["<b>Writer:</b> агент в runtime"]
        C_owner["<b>Owner:</b> никому,<br/>не хранится долго"]
        C_ex["Промпт-сборка под один LLM-вызов:<br/>что подобрано из Персоны и Памяти<br/>именно сейчас"]
    end

    Persona -.->|"подаёт явные<br/>ценности и заметки"| Context
    Memory -.->|"подаёт релевантную<br/>историю и агрегаты"| Context

    classDef persona fill:#d4edda,stroke:#28a745,stroke-width:2px,color:#000
    classDef memory fill:#fff3cd,stroke:#ffc107,stroke-width:2px,color:#000
    classDef context fill:#cce5ff,stroke:#007bff,stroke-width:2px,color:#000
    class Persona persona
    class Memory memory
    class Context context
```

## Сравнительная матрица

| Слой | Writer (кто пишет) | Owner (кому принадлежит) | TTL | Контролирую ли я? |
|---|---|---|---|---|
| **Персона** | Я сам | Моё | Постоянно | Да: могу прочитать, изменить, удалить |
| **Память** | Система автоматически | Носитель системы | От события до удержания носителя | Зависит от носителя: на моём ноуте — да, на чужой платформе — по политике сервиса |
| **Контекст** | Агент в runtime | Никому | До конца LLM-вызова | Косвенно: через промпт и инструкции агенту |

## Тест границы

> **«Что пропадёт, если удалю X?»**

- Удалил Git-репо со своими заметками → пропала **Персона**.
- Удалил Neon БД (или локальную SQLite, или историю чатов в ChatGPT) → пропала **Память**.
- Прервал LLM-вызов → пропал **Контекст**.

Если три ответа сходятся в одну точку («у меня есть Notion и больше ничего») — у вас всё в одном слое, и при потере носителя теряется сразу всё.

## Зачем различать

Когда ИИ «знает обо мне», вопрос «откуда» имеет три разных ответа:

1. Из **Персоны** — я сам положил, могу удалить, я владею.
2. Из **Памяти** — система записала автоматически. Где носитель? Какая политика? Кто ещё видит?
3. Из **Контекста** — это сборка именно сейчас, исчезнет с концом сессии.

Без этого различения разговор «у меня есть второй мозг» превращается в туман. Метафора «второй мозг» плоская: она прячет, **где** моё, а где **системы**.

## Парная иллюстрация: Экзоскелет ≠ Автопилот (DP.D.046)

> Слоистая модель отвечает на «**где** моё». Различение «экзоскелет vs автопилот» — на «**в каком режиме** я работаю с этим всем».

```mermaid
flowchart LR
    Decision["Решение,<br/>в котором<br/>участвовал ИИ"]

    Decision --> Test{"Могу объяснить<br/>решение БЕЗ фразы<br/>«ИИ подсказал»?"}

    Test -->|"Да"| Exo["🟢 ЭКЗОСКЕЛЕТ<br/>Я удерживаю human gate<br/>ИИ усиливает мышление<br/>Личность растёт"]
    Test -->|"Нет"| Auto["🔴 АВТОПИЛОТ<br/>LLM решил автономно<br/>Я принял, не понимая шага<br/>Растёт зависимость, не личность"]

    classDef decision fill:#e9ecef,stroke:#495057,stroke-width:2px,color:#000
    classDef question fill:#fff3cd,stroke:#ffc107,stroke-width:2px,color:#000
    classDef good fill:#d4edda,stroke:#28a745,stroke-width:2px,color:#000
    classDef bad fill:#f8d7da,stroke:#dc3545,stroke-width:2px,color:#000
    class Decision decision
    class Test question
    class Exo good
    class Auto bad
```

**Связка:** удерживать human gate проще, когда понимаешь, **из какого слоя** ИИ взял аргументы для совета. Если из Персоны (моё) — я могу проверить источник. Если из Памяти системы — спросить, что именно было подобрано. Если только из Контекста — это его собственная сборка, которую я могу принять или отклонить.
