# IWE из браузера: открыт для всех подписчиков

![IWE Gateway — открытый доступ](https://raw.githubusercontent.com/TserenTserenov/DS-Knowledge-Index-Tseren/main/docs/2026/09-%D0%B0%D0%BF%D1%80%D0%B5%D0%BB%D1%8C/114-2026-04-15-gateway-open-access/cover.png)

Главная жалоба на IWE с самого начала: «Звучит интересно, но я не программист. Git, терминал, VS Code — это не моё».

Слышу. Именно поэтому последний месяц делал версию без всего этого. Сегодня открываю её для всех подписчиков «Бесконечного развития».

## Как это выглядит теперь

Открываешь браузер. Заходишь в claude.ai. Задаёшь вопрос.

Claude знает методологию МИМ — 5000+ документов: руководства, курсы, понятия. Знает тебя — твои цели, уровень, что уже проходил. Если захочешь сохранять свои мысли и заметки — он создаст для тебя личное хранилище сам, в ходе разговора.

Никакого терминала. Никаких команд. Никакой настройки.

## Как подключить

Четыре шага, пять минут.

**1.** Открой [claude.ai/settings/connectors](https://claude.ai/settings/connectors)

**2.** Нажми **Add custom connector**

**3.** Заполни два поля:
- Name: `IWE`
- URL: `https://mcp.aisystant.com/mcp`

**4.** Нажми **Connect** — появится форма входа. Email и пароль от system-school.ru.

Нужна подписка Claude Pro и активная подписка «Бесконечное развитие».

В новом чате напиши: **«С чего мне начать?»**

## Что спрашивать

Несколько вопросов, с которых удобно начать:

— «Что такое системное мышление и зачем оно мне?»  
— «Навигатор, с чего мне начать изучение?»  
— «Диагност, определи мою ступень»  
— «Покажи мой профиль»

Если захочешь сохранить что-то важное из разговора — скажи: «Запомни это» или «Хочу личную базу знаний». Claude предложит создать пространство и сделает это сам.

## Что дальше

Следующее — убрать последний шаг ручной настройки: сейчас при создании личной базы нужно один раз авторизовать GitHub. Хочу сделать так, чтобы это тоже происходило само.

Для тех, кто готов к большему: есть версия для VS Code с планированием дня и автоматическими отчётами. Но начать можно прямо сейчас, из браузера.
