# Открытые репозитории IWE и Knowledge MCP: полный список

![Репо и Gateway](https://raw.githubusercontent.com/TserenTserenov/DS-Knowledge-Index-Tseren/main/docs/2026/09-%D0%B0%D0%BF%D1%80%D0%B5%D0%BB%D1%8C/2026-04-03-099-open-repos-knowledge-mcp/illustration.png)

Когда ИИ-ассистент работает в Intellectual Work Environment (IWE), он ищет по базе знаний. За доступ к знаниям МИМ отвечает **Knowledge MCP** (`knowledge-mcp`) — сервис, через который ассистент получает доступ к методологии интеллектуальной работы (МИМ), паспортам предметных областей, руководствам и документации платформы.

Все эти материалы лежат в открытых репозиториях на GitHub. Ниже — полный список с описанием и ссылками. Доступ бесплатный: достаточно присоединить IWE, и ассистент сразу знает методологию.

## Личные репозитории (у каждого пользователя — свои)

Помимо платформенного знания, у каждого пользователя IWE формируются собственные репозитории — личная база знаний. Они не входят в общий `knowledge-mcp`, к ним доступ только у владельца через его личный mcp (мы предложим сервисное решение для каждого пользователя – `personal-knowledge-mcp`).

Примеры личных репозиториев (на моём примере):

| Репозиторий | Что содержит |
|-------------|-------------|
| **DS-my-strategy** | Личное стратегирование — WeekPlan, DayPlan, результаты, рефлексия |
| **DS-Knowledge-Index-Tseren** | Персональный индекс знаний — заметки, посты, публикации |
| **DS-creator-development** | Репо, в которое платформа Aisystant будет доставлять персональное руководство — трек роста, персональное задание на каждый день |
| **DS-autonomous-agents** | Эксперименты с агентами — код и заметки |

У меня в личном MCP проиндексировано ещё ~3 100 документов поверх платформенных.

## Как это работает сейчас и что изменится

Доступ к материалам МИМ через платформенный `knowledge-mcp` уже работает и предоставляется бесплатно каждому пользователю. Пользователю достаточно присоединить IWE — и ассистент сразу знает методологию, терминологию, практики. Никакой дополнительной настройки.

А вот с личной базой знаний до сих пор было сложнее. Чтобы ИИ-ассистент видел ваши собственные репозитории — стратегию, заметки, проекты и тп — пользователю приходилось самостоятельно настраивать личный MCP: создавать индекс, прописывать endpoint, поддерживать синхронизацию. Для технаря еще терпимо, а для остальных — это непреодолимый барьер.

Мы это убираем. Вместо ручной настройки появится **Knowledge Gateway** — единая точка входа, за которой стоят три MCP-сервиса:

1. **`knowledge-mcp`** — платформенное знание (МИМ, принципы, паспорта предметных областей). Общее для всех, без авторизации на чтение. Это уже есть.
2. **`personal-knowledge-mcp`** — личная база знаний пользователя. Репозитории, которые пользователь выбрал для индексации. Изоляция по `user_id` — никто не видит чужие данные. Почти готово.
3. **`digital-twin-mcp`** — цифровой двойник пользователя. Прогресс, профиль, активные области развития. Это уже есть.

Пользователю нужно будет подключить один адрес — Knowledge Gateway. Всё остальное наша платформа делает сама: индексирует репозитории, изолирует данные, обновляет при изменениях, соберет цифровой двойник. Один раз подключил — ассистент знает и методологию, и тебя.

Knowledge Gateway — это стандартный MCP-сервер. Его можно подключить к любой LLM, которая поддерживает MCP через connect: Claude Code, Claude Desktop, Cursor, Windsurf, ChatGPT и другие. Не привязан к одному провайдеру — работает там, где работаешь ты. Надеюсь, что скоро начнем тестирование. Буду рад за замечания и предложения.
