# Knowledge Gateway: IWE теперь доступен из браузера

До сих пор IWE работал только через Claude Code в VS Code. Это давало полный экзокортекс, но создавало три проблемы:

1. **Сложная установка.** VS Code, Claude Code CLI, настройка MCP-серверов, git, API-ключи -- порог входа слишком высокий для нетехнического пользователя.
2. **Смешанные знания.** Платформенные знания (Pack МИМ, курсы, руководства) и личные заметки пользователя хранились вместе в одном MCP-сервере. Нет разделения -- нет изоляции, нет масштабирования на других пользователей.
3. **Привязка к десктопу.** Нет доступа с телефона, из другого AI-клиента, из браузера без установки.

Knowledge Gateway -- единый URL, который решает все три проблемы. Знания разделены на платформенные (L2) и личные (L4), авторизация через Ory, подключение -- за несколько минут из браузера.

## Как это устроено

```
  claude.ai  /  ChatGPT  /  Cursor  /  бот
                    |
              mcp.aisystant.com
             OAuth 2.1 (Ory Hydra)
                    |
       +------------+------------+
       |            |            |
  Knowledge    Personal     Digital
  MCP (L2)     MCP (L4)      Twin
  Pack, курсы  GitHub-репо   профиль,
  руководства  пользователя  показатели
```

Один URL объединяет три MCP-сервера. Авторизация через Ory -- тот же логин, что и на system-school.ru.

## Подключение через claude.ai

**Шаг 1.** Зайди на [claude.ai](https://claude.ai) и зарегистрируйся (если ещё нет аккаунта).

**Шаг 2.** Оформи [подписку «Бесконечное развитие»](#зачем-нужна-подписка-бесконечное-развитие) на [system-school.ru](https://system-school.ru). При регистрации создаётся единый аккаунт Ory.

**Шаг 3.** Подключи Gateway:
- Открой [https://claude.ai/settings/connectors](https://claude.ai/settings/connectors)
- Нажми **Add custom connector**
- В поле **Name** напиши: `IWE`
- В поле **URL** вставь: `https://mcp.aisystant.com/mcp`
- Нажми **Add**, затем **Connect**
- Откроется форма входа Ory -- введи email и пароль от Aisystant
- Появится статус **Connected to IWE** -- готово

**Шаг 4 (опционально).** Подключи личные знания через GitHub.

Этот шаг нужен, если ты готов развивать своё ядро знаний -- вести заметки, стратегию, рабочие документы в GitHub-репозиториях. Без GitHub Gateway работает в режиме чтения: поиск по Pack, курсам, Цифровому Двойнику.

- Зарегистрируйся на [github.com](https://github.com) (если ещё нет аккаунта)
- В чате с claude.ai напиши: «Подключи мой GitHub» -- AI вызовет инструмент `github_connect` и даст ссылку для установки
- Выбери репозитории, к которым хочешь дать доступ -> Install -> готово, репо автоматически индексируются

Если у тебя ещё нет репозиториев -- не страшно. Можно создать первый прямо на GitHub (кнопка New repository), назвать его как угодно (например, `my-strategy` или `notes`) и подключить позже.

## Подключение через Cursor, Windsurf, Cline

Эти IDE поддерживают remote MCP-серверы через конфигурационный файл.

**Cursor:** Settings (Cmd+,) -> Features -> MCP -> Add New MCP Server. Transport: `streamable-http`. URL: `https://mcp.aisystant.com/mcp`. При первом подключении откроется OAuth-авторизация через Ory.

**Windsurf / Cline:** добавь в конфиг `mcpServers`:

```json
{
  "mcpServers": {
    "iwe": {
      "url": "https://mcp.aisystant.com/mcp"
    }
  }
}
```

При первом вызове инструмента пройдёт OAuth-авторизация.

## Другие AI-клиенты (ChatGPT, Gemini и др.)

Остальные вендоры пока не сделали простого способа подключить пользовательские знания через MCP. Но для OpenAI есть чуть более сложный вариант -- Developer Mode.

**ChatGPT (Developer Mode)** -- доступен в планах Business, Enterprise и Edu:

1. Включи Developer Mode: Workspace Settings -> Permissions & Roles -> Connected Data -> Developer mode
2. Добавь новый MCP-коннектор
3. URL: `https://mcp.aisystant.com/mcp`
4. Авторизация пройдёт через OAuth (Ory)

Подробная инструкция: [help.openai.com](https://help.openai.com/en/articles/12584461-developer-mode-apps-and-full-mcp-connectors-in-chatgpt-beta)

Gemini пока не поддерживает MCP. Как только появится -- Gateway будет работать без изменений, тот же URL.

## Что можно делать через Gateway

| Возможность | Нужен GitHub? | Пример запроса |
|---|---|---|
| Поиск по Pack (методологии, принципы) | Нет | «Что такое системное мышление?» |
| Поиск по курсам и руководствам | Нет | «Как пройти Практики саморазвития?» |
| Цифровой Двойник (профиль, цели) | Нет | «Покажи мой профиль» |
| Роли (Навигатор, Диагност) | Нет | «Навигатор, с чего начать?» |
| Инструкции IWE (контекст платформы) | Нет | Загружаются автоматически |
| Поиск по своим заметкам | Да | «Найди мои записи про стратегию» |
| Запись в свои репо | Да | «Запиши инсайт в inbox/» |
| Удаление файлов из репо | Да | «Удали черновик inbox/old-note.md» |

## Сравнение интерфейсов IWE

| Возможность | Бот (Telegram) | Браузер (claude.ai) | IDE (Cursor и др.) | VS Code (Claude Code) |
|---|---|---|---|---|
| Подписка БР | да | да | да | да |
| Поиск по знаниям (L2 платформа) | да | да | да | да |
| Цифровой Двойник | да | да | да | да |
| Роли (Навигатор, Диагност) | да | да | да | да |
| Чтение личных знаний (L4) | да | да | да | да |
| Запись в личные репо | -- | да | да | да |
| Удаление из личных репо | -- | да | да | да |
| Git, терминал, файлы | -- | -- | частично (файлы IDE) | да |
| 14 элементов культуры работы | частично (экзоскелетный режим, самоисправление) | частично (+ захват знания, организация знаний) | частично (+ захват знания, организация знаний) | все 14 |
| Мобильный доступ | да | да | -- | -- |
| Без установки | да | да | нет | нет |

**14 элементов культуры работы** (DP.M.008): ОРЗ, каскад планирования, ритуал учёта времени, организация структуры знаний, ВДВ, захват знания, АрхГейт, стоп-краны, осторожный мультитаскинг, мультиагентность, экзоскелетный режим, самоисправление, стоп-лист, эволюция системы.

Сейчас через Gateway доступны 4 из 14 элементов. По мере развития серверных агентов Gateway будет приближаться к полному экзокортексу -- до 11 из 14.

## Для кого

- **Все участники с подпиской** -- быстрый вопрос к Pack из любого устройства
- **Нетехнические участники** -- не нужен VS Code, терминал, git
- **Мобильные сценарии** -- вопрос к знаниям платформы с телефона
- **Несколько AI-клиентов** -- один Gateway, подключай из claude.ai, ChatGPT, Cursor

## Ищу первых пользователей

Ищу 3-5 участников клуба, которые подключат Gateway и дадут обратную связь. Что работает, что ломается, что непонятно в инструкции. Интересно -- напиши в клубе или в ЛС.

## Зачем нужна подписка «Бесконечное развитие»

Gateway авторизует пользователей через Ory -- тот же аккаунт, что и на [system-school.ru](https://system-school.ru). Подписка «Бесконечное развитие» даёт:

- Доступ к **платформенному знанию** (L2): Pack МИМ, курсы, руководства, принципы -- 3000+ документов
- **Цифровой Двойник**: профиль, показатели, цели
- **Личное знание** (L4, через GitHub): поиск, запись и удаление файлов в своих репозиториях
- **Роли**: Навигатор (траектория развития) и Диагност (определение ступени мастерства)

Без подписки Gateway недоступен -- авторизация не пройдёт.
