# Knowledge Gateway: IWE теперь доступен из браузера

Knowledge Gateway -- единый URL, через который любой AI-клиент получает доступ к знаниям платформы, личным заметкам и Цифровому Двойнику. Один адрес, одна авторизация -- работает из браузера, с телефона, без установки.

## Зачем нужна подписка «Бесконечное развитие»

Gateway авторизует пользователей через Ory -- тот же аккаунт, что и на system-school.ru. Подписка «Бесконечное развитие» даёт:

- Доступ к **платформенному знанию** (L2): Pack МИМ, курсы, руководства, принципы -- 3000+ документов
- **Цифровой Двойник**: профиль, показатели, цели
- **Личное знание** (L4, через GitHub): поиск, запись и удаление файлов в своих репозиториях
- **Роли**: Навигатор (траектория развития) и Диагност (определение ступени мастерства)

Без подписки Gateway недоступен -- авторизация не пройдёт.

## Как это устроено

```
  claude.ai  /  ChatGPT  /  Cursor  /  бот
                    |
              mcp.aisystant.com
             OAuth 2.1 (Ory Hydra)
                    |
       +------------+------------+
       |            |            |
  Knowledge    Personal     Digital
  MCP (L2)     MCP (L4)      Twin
  Pack, курсы  GitHub-репо   профиль,
  руководства  пользователя  показатели
```

Один URL объединяет три MCP-сервера. Авторизация через Ory -- тот же логин, что и на system-school.ru.

## Подключение через claude.ai

**Шаг 1.** Зайди на [claude.ai](https://claude.ai) и зарегистрируйся (если ещё нет аккаунта).

**Шаг 2.** Оформи подписку «Бесконечное развитие» на [system-school.ru](https://system-school.ru). При регистрации создаётся единый аккаунт Ory.

**Шаг 3.** Подключи Gateway:
- Открой [https://claude.ai/settings/connectors](https://claude.ai/settings/connectors)
- Нажми **Add custom connector**
- В поле **Name** напиши: `IWE`
- В поле **URL** вставь: `https://mcp.aisystant.com/mcp`
- Нажми **Add**, затем **Connect**
- Откроется форма входа Ory -- введи email и пароль от Aisystant
- Появится статус **Connected to IWE** -- готово

**Шаг 4 (опционально).** Подключи личные знания через GitHub.

Этот шаг нужен, если ты готов развивать своё ядро знаний -- вести заметки, стратегию, рабочие документы в GitHub-репозиториях. Без GitHub Gateway работает в режиме чтения: поиск по Pack, курсам, Цифровому Двойнику.

- Зарегистрируйся на [github.com](https://github.com)
- Создай репозиторий для заметок
- В чате с claude.ai напиши: «Подключи мой GitHub» -- AI вызовет инструмент `github_connect` и даст ссылку для установки
- Выбери репозитории -> Install -> готово, репо автоматически индексируются

## Подключение через ChatGPT

ChatGPT поддерживает remote MCP через Developer Mode (доступен в планах Business, Enterprise и Edu).

**Шаг 1.** Включи Developer Mode: Workspace Settings -> Permissions & Roles -> Connected Data -> Developer mode.

**Шаг 2.** Добавь MCP-коннектор:
- Перейди в настройки коннекторов
- Добавь новый MCP-сервер
- URL: `https://mcp.aisystant.com/mcp`
- Авторизация пройдёт через OAuth (Ory)

Подробная инструкция: [help.openai.com](https://help.openai.com/en/articles/12584461-developer-mode-apps-and-full-mcp-connectors-in-chatgpt-beta)

## Подключение через Cursor, Windsurf, Cline

Эти IDE поддерживают remote MCP-серверы через конфигурационный файл.

**Cursor:** Settings (Cmd+,) -> Features -> MCP -> Add New MCP Server. Transport: `streamable-http`. URL: `https://mcp.aisystant.com/mcp`. При первом подключении откроется OAuth-авторизация через Ory.

**Windsurf / Cline:** добавь в конфиг `mcpServers`:

```json
{
  "mcpServers": {
    "iwe": {
      "url": "https://mcp.aisystant.com/mcp"
    }
  }
}
```

При первом вызове инструмента пройдёт OAuth-авторизация.

## Что можно делать через Gateway

| Возможность | Нужен GitHub? | Пример запроса |
|---|---|---|
| Поиск по Pack (методологии, принципы) | Нет | «Что такое системное мышление?» |
| Поиск по курсам и руководствам | Нет | «Как пройти Практики саморазвития?» |
| Цифровой Двойник (профиль, цели) | Нет | «Покажи мой профиль» |
| Роли (Навигатор, Диагност) | Нет | «Навигатор, с чего начать?» |
| Инструкции IWE (контекст платформы) | Нет | Загружаются автоматически |
| Поиск по своим заметкам | Да | «Найди мои записи про стратегию» |
| Запись в свои репо | Да | «Запиши инсайт в inbox/» |
| Удаление файлов из репо | Да | «Удали черновик inbox/old-note.md» |

## Чем отличается Gateway от Claude Code (VS Code)

| | VS Code (Claude Code) | Браузер через Gateway |
|---|---|---|
| Полный экзокортекс (файлы, git, протоколы) | да | -- |
| Знания (Pack, курсы, личные) | да | да |
| Запись в GitHub | да (git) | да (API) |
| Цифровой Двойник | да | да |
| Роли (Навигатор, Диагност) | да | да |
| Мобильный доступ | -- | да |
| Без установки | -- | да |

Gateway -- окно в знания, не замена Claude Code. VS Code = полный экзокортекс с протоколами и git. Gateway = доступ из любого браузера, включая телефон.

## Для кого

- **Все участники с подпиской** -- быстрый вопрос к Pack из любого устройства
- **Нетехнические участники** -- не нужен VS Code, терминал, git
- **Мобильные сценарии** -- вопрос к знаниям платформы с телефона
- **Несколько AI-клиентов** -- один Gateway, подключай из claude.ai, ChatGPT, Cursor
