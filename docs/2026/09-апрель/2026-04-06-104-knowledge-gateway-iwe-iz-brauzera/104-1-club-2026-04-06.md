# Knowledge Gateway: скоро IWE будет доступен из браузера

До сих пор IWE работал только через Claude Code в VS Code. Это давало полный экзокортекс, но создавало три проблемы:

1. **Сложная установка.** VS Code, Claude Code CLI, настройка MCP-серверов, git, API-ключи -- порог входа слишком высокий для нетехнического пользователя.
2. **Смешанные знания.** Платформенные знания (Pack МИМ, курсы, руководства) и личные заметки пользователя хранились вместе в одном MCP-сервере. Нет разделения -- нет изоляции, нет масштабирования на других пользователей.
3. **Привязка к десктопу.** Нет доступа с телефона, из другого AI-клиента, из браузера без установки.

Сегодня запустил Knowledge Gateway v2.0 -- единый URL, который решает все три проблемы. Знания разделены на платформенные (L2) и личные (L4), авторизация через Ory, подключение -- за 1 минуту из браузера.

## Как это работает

```
  claude.ai  /  ChatGPT  /  Gemini  /  бот
                    |
              mcp.aisystant.com
             OAuth 2.1 (Ory Hydra)
                    |
       +------------+------------+
       |            |            |
  Knowledge    Personal     Digital
  MCP (L2)     MCP (L4)      Twin
  Pack, курсы  GitHub-репо   профиль,
  руководства  пользователя  показатели
```

Один URL объединяет три MCP-сервера. Авторизация через Ory -- тот же логин, что и на system-school.ru. Подключил один раз -- работает во всех чатах.

## Как подключить (3 минуты)

Каждый шаг -- если уже сделано, пропускай.

**Шаг 1.** Зарегистрируйся на [claude.ai](https://claude.ai).

**Шаг 2.** Оформи подписку «Бесконечное развитие» на [system-school.ru](https://system-school.ru). При регистрации создаётся единый аккаунт Ory.

**Шаг 3.** Подключи Gateway:
- claude.ai -> Settings -> Connectors -> Add custom connector
- URL: `https://mcp.aisystant.com/mcp`
- Add -> Connect -> форма входа Ory -> email и пароль от Aisystant
- "Connected to IWE" -- готово

**Шаг 4 (опционально).** Подключи личные знания через GitHub:
- Зарегистрируйся на [github.com](https://github.com)
- Создай репозиторий для заметок
- Установи GitHub App: [github.com/apps/aisystant-knowledge/installations/new](https://github.com/apps/aisystant-knowledge/installations/new) -> выбери репо -> Install

## Что можно делать

| Возможность | Нужен GitHub? | Пример |
|---|---|---|
| Поиск по Pack (методологии, принципы) | Нет | «Что такое системное мышление?» |
| Поиск по курсам и руководствам | Нет | «Как пройти Практики саморазвития?» |
| Цифровой Двойник (профиль, цели) | Нет | «Покажи мой профиль» |
| Поиск по своим заметкам | Да | «Найди мои записи про стратегию» |
| Запись в свои репо | Да | «Запиши инсайт в inbox/» |

## Чем отличается от VS Code

| | VS Code (Claude Code) | claude.ai через Gateway |
|---|---|---|
| Полный экзокортекс (файлы, git, протоколы) | да | -- |
| Знания (Pack, курсы, личные) | да | да |
| Запись в GitHub | да (git) | да (API) |
| Цифровой Двойник | да | да |
| Мобильный доступ | -- | да |
| Без установки | -- | да |

Gateway -- окно в знания, не замена VS Code. VS Code = полный экзокортекс с протоколами и git. Gateway = доступ из любого браузера, включая телефон.

## Для кого

- Нетехнические участники -- не нужен VS Code, терминал, git
- Мобильные сценарии -- быстрый вопрос к Pack из телефона
- Несколько аккаунтов AI -- один IWE, несколько AI-клиентов

## Скоро

- **Подключение личных знаний для всех пользователей.** Сейчас GitHub-интеграция работает в пилотном режиме. **Следующий шаг -- автоматическая привязка GitHub App к аккаунту Aisystant и индексация репо нового пользователя без ручных настроек.**
- Инструкции IWE (роли, правила) как MCP prompt -- чтобы claude.ai знал контекст платформы
- Роли (Навигатор, Диагност) через Gateway
- ChatGPT и Gemini -- когда поддержат MCP Connectors
