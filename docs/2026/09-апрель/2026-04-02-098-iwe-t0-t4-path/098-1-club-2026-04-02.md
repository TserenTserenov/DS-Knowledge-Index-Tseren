# От /start до IWE за 5 шагов: как устроен путь пользователя

Когда меня спрашивают «а что вы продаёте?», я раньше начинал объяснять про методологию, экзокортекс, цифрового двойника. Глаза собеседника стекленели на второй минуте.

Сегодня я могу ответить в одном предложении: **мы даём полную рабочую среду для интеллектуальной работы, где ИИ растёт вместе с тобой — от справочника до со-мыслителя.**

Вот как это устроено.

## Пять тиров: от Telegram до собственной среды

Каждый тир — не уровень доступа, а конфигурация среды. Ты не «повышаешься» — ты расширяешь инструменты по мере готовности.

### T0: Старт (5 мин, нужен только Telegram)

Написал `/start` боту — и на 30 дней получил полный доступ ко всему. Не к демо-версии, не к огрызку функций — ко всему, включая программы, цифрового двойника и полную рабочую среду.

Что остаётся бесплатно навсегда: поиск по базе знаний МИМ. Это 5000+ документов — методология интеллектуальной работы, накопленная за 30 лет.

### T1: Регистрация (email, 5 мин)

Зарегистрировался — данные стали кросс-системными (бот, веб, LMS). Открылись руководства, клуб, консультант по базе знаний, 14-дневный марафон. ИИ пока ассистент — знает домен, помогает по запросу.

### T2: Подписка БР (единственная точка оплаты)

Это единственный момент, где нужно заплатить. Одна подписка — и всё включено: программы (ЛР/РР/ИР), проверка домашних заданий, расширенный доступ к ИИ. Модель не нужен — платформа сама предоставляет доступ к Claude, GPT и другим моделям. Никаких API-ключей.

ИИ становится экспертом — знает не только домен, но и тебя.

### T3: Персонализация (20 мин, бесплатно)

Заполняешь цифрового двойника через бота — 20 минут ответов на вопросы. После этого ИИ знает твои цели, уровень, текущие проблемы. Включается типовая методология платформы (FPF, протоколы, различения). Ответы становятся персональными.

ИИ теперь наставник — мыслит по первым принципам и знает тебя глубоко. Открывается публикация в клубе через IWE.

### T4: Активация IWE (5 мин, бесплатно)

Регистрируешься в GitHub — платформа автоматически создаёт твою рабочую среду (форк шаблона). Получаешь Gateway URL — одну ссылку, которую подключаешь к любому ИИ-клиенту: claude.ai, ChatGPT, Cursor, Gemini.

**IWE = Intellectual Work Environment** — полная рабочая среда: бот + Gateway + экзокортекс + цифровой двойник + git-репо + агенты + методология (типовая + личная) + база знаний МИМ.

Gateway — это 3 MCP-сервера через единый URL:
- **knowledge-mcp** — знания платформы (методология, курсы, руководства)
- **digital-twin-mcp** — твой цифровой двойник
- **personal-knowledge-mcp** — твоя личная база знаний

Добавляются: личная методология (свой CLAUDE.md), персональное руководство, серверные агенты (Стратег, Экстрактор, Синхронизатор), WakaTime для трекинга времени.

ИИ — со-мыслитель. Полный контекст, личная методология.

## Что бесплатно, за что деньги

Простой ответ: **одна подписка — и всё включено.** Тиры T3 и T4 — бесплатные апгрейды, которые ты активируешь действиями (заполни анкету / зарегистрируйся в GitHub).

Платформа берёт на себя даже API-ключи — тебе не нужен свой аккаунт Anthropic или OpenAI. Мы предоставляем ИИ как сервис: оптимальная модель для каждой задачи, лимит токенов по тарифу.

А 30-дневный триал даёт попробовать всё это до покупки.

## Что дальше: апрель 2026

Сейчас работаем над:
- **Knowledge Gateway MVP** (WP-187) — единый MCP-эндпоинт для любого ИИ-клиента
- **Платформенный LLM Proxy** (WP-200) — ИИ как сервис без личных API-ключей
- **Серверные агенты** (WP-201) — агенты работают на платформе, результат в твоём GitHub
- **Связка бот-Ory** — единая авторизация для всех тиров

Цель — чтобы к концу апреля первый нетехнический пользователь мог пройти весь путь T0→T4 за один день.
