## Чего НЕ будет

Сразу расставлю ожидания.

**Не будет лекции.** Семинар начинается с живого демо — моё утро с IWE. 25 минут реальной работы: как открывается сессия, как агент проверяет план, как захватываются знания, как закрывается день. Всё на реальных данных.

**Не будет программирования.** Вы не будете писать код. Но увидите, как среда разработчика (VS Code + Claude Code) становится средой для интеллектуальной работы любого специалиста. И получите чек-лист, как это развернуть — без навыков разработки.

**Не будет продажи подписки.** Семинар — самодостаточный продукт. Вы уйдёте с конкретными материалами и шаблоном, который можно форкнуть и начать использовать.

## Что БУДЕТ

### 1. Живое демо: моё утро с IWE

Главный блок. Я открываю свою рабочую среду и показываю:
- Как агенты работают в своих зонах: Стратег планирует день, Экстрактор захватывает знания, Синхронизатор обновляет базы, Публикатор выпускает посты по расписанию
- Как выглядит рабочая сессия: Открытие → Работа → Закрытие — и почему этот протокол меняет всё
- Как бот в Telegram отвечает из проверенной базы знаний (5400+ документов), а не галлюцинирует
- Как 22 репозитория связаны единой архитектурой

Это живая система, которой я пользуюсь каждый день. Не скриншоты, не слайды.

### 2. Как работают ИИ-агенты: аналогия с наймом сотрудника

Большинство людей пропускают главный этап. Представьте, что ИИ — это сотрудник:

1. **Обучение** — кто-то обучил базовую модель (Anthropic, OpenAI)
2. **Найм** — вы подключили подписку или API
3. **Онбординг** — вы дали контекст: цели, знания, протоколы работы
4. **Задание** — промпт на конкретную задачу
5. **Приёмка** — проверка результата

Большинство перепрыгивают с шага 2 сразу на шаг 4. Наняли — и сразу задачу. Без онбординга. А потом удивляются: «Почему ИИ не понимает мою ситуацию?»

IWE — это и есть инфраструктура онбординга. На семинаре разберём, как она устроена.

### 3. Три слоя пользы

Не все хотят одного и того же. Поэтому среда работает на трёх уровнях:

- **Стандарты** — бот отвечает из проверенной базы знаний, помогает с тестами, ведёт марафон. Работает сразу после подключения.
- **Работа со знаниями** — экзокортекс: агенты помогают планировать, захватывать знания, фиксировать результаты. Требует GitHub и VS Code.
- **Расширенные возможности** — публикация в клуб, WakaTime-статистика, персональные отчёты. Подключаются по мере роста.

На семинаре покажу все три — и вы решите, с какого слоя начать.

### 4. Как начать: чек-лист развёртывания

7 шагов от нуля до работающей среды:
- VS Code → Git → Claude Code → шаблон экзокортекса → бот
- Что нужно установить, что настроить, где могут быть сложности
- Какие требования: компьютер, GitHub-аккаунт, ключ Claude API

Вы получите этот чек-лист и шаблон-репозиторий для форка.
