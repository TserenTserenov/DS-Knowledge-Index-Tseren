# Семинар за спиной, архитектура под капотом, творческий конвейер замкнут: W10, 23 фев — 1 мар

Десятая неделя года закончилась семинаром «От экзокортекса к IWE» 28 февраля. Три часа живого разбора — шестеро участников прислали свои кейсы, я готовил персональные рекомендации по каждому. Получилось шесть разных историй: от дизайнера с разрывом между личным развитием и работой до предпринимателя с тремя несвязанными доменами. Каждый случай показал, где именно люди теряют фокус и как экзокортекс может это изменить.

Пока шла подготовка к семинару, параллельно велась работа над новой архитектурой платформы Aisystant. 16 принципов, 14 архитектурных решений (ADR), 63 сервиса в каталоге. Главное изменение — тарифная политика стала двухслойной: подписка на платформу (четыре тира от T1 до T4) плюс события по запросу — семинары, практикумы, резидентуры. Раньше была одноуровневая модель с токенами, теперь — система баллов, которая начисляется за активность и умножается в зависимости от тира. Это позволяет людям двигаться между уровнями плавно, а не прыгать через пропасть цен.

Ещё одна крупная вещь — формализация творческого конвейера. Раньше заметки сыпались в один fleeting-notes.md, и там был хаос: что-то надо в Pack, что-то в пост, что-то — просто шум. Теперь семь категорий с чёткими критериями: Знания (в Pack), Опыт (в обучение), Стимулы (в Dissatisfactions), Ответы (в FAQ), Задачи (в backlog), Черновики (в drafts/), Шум (в архив). Каждая заметка проходит через автоматический разбор (Note-Review), и система сама предлагает маршрут. Человек только подтверждает или корректирует. Конвейер замкнут — ничего не теряется.

Внутри платформы знаний появилось новое различение: Project ≠ System (D.102). Проект — это ограниченная во времени работа с известным результатом. Система — бесконечная, эволюционирующая структура. Экзокортекс — система, а не проект. Бот — система. Семинар — проект. Развитие — система. Кажется очевидным, но когда начинаешь применять это различение к планированию, становится понятно, почему так много людей бросают обучение: они пытаются сделать из системы проект, назначают дедлайн на «стать экспертом» и выгорают.

Для участников клуба самое полезное на этой неделе — шаблон экзокортекса (FMT-exocortex-template) вышел на финишную прямую. Добавлен Setup Guide для новичков, MCP-интеграция (два сервера: knowledge-mcp и digital-twin-ddt), модульная архитектура ролей (role.yaml + autodiscovery). Теперь любой желающий сможет развернуть базовую версию за один вечер: Claude Code + VS Code + GitHub + launchd. Smoke test ещё не пройден, но основная структура готова.

Метрики недели: 442 коммита в 15 репозиториях, завершено 11 из 20 рабочих продуктов (55% completion rate, на 5% выше, чем в W09). Восемь дней активности из семи — захватил воскресенье следующей недели. Carry-over на W11: доделать спецификации модулей для новой архитектуры, ревью руководства «Методы саморазвития» (переименовали «практика» на «метод» в 1522 местах), разгрести backlog бота (семь задач техдолга, три развития).

На следующей неделе фокус — завершить то, что в процессе, а не открывать новое. Архитектура платформы должна дойти до Phase 2, руководство «Методы саморазвития» — слиться в основную ветку, бот — получить консультирование по установке IWE и улучшенный UX тренировки. Никакой героики — только методичное закрытие параллельных задач.
