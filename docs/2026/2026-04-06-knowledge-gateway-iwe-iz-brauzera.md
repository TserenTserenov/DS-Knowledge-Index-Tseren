# Knowledge Gateway: IWE теперь доступен из браузера

> 6 апреля 2026. IWE Knowledge Gateway v2.0 — один URL для доступа ко всей платформе знаний из любого AI-клиента.

## Что произошло

IWE Knowledge Gateway (`mcp.aisystant.com`) получил поддержку Streamable HTTP и OAuth. Теперь его можно подключить как Connector в claude.ai — и работать с платформенными знаниями, личными заметками и Цифровым Двойником прямо из браузера. Без VS Code, без терминала, без настройки.

## Архитектура

```
  claude.ai  /  ChatGPT  /  Gemini  /  Telegram-бот  /  VS Code
                          |
                    mcp.aisystant.com
                   OAuth 2.1 (Ory Hydra)
                          |
         +----------------+----------------+
         |                |                |
   Knowledge MCP    Personal MCP     Digital Twin
   (L2 платформа)   (L4 личные)      (профиль)
   Pack, курсы,     GitHub-репо       цели, показатели,
   руководства      пользователя      ступень мастерства
```

## Как подключить

> Каждый шаг — если уже сделано, пропускай.

**Шаг 1.** Зарегистрируйся на [claude.ai](https://claude.ai)

**Шаг 2.** Оформи подписку «Бесконечное развитие» на [system-school.ru](https://system-school.ru). При регистрации создаётся аккаунт Ory (единая авторизация платформы).

**Шаг 3.** Подключи Gateway:
1. claude.ai -> Settings -> Connectors -> **Add custom connector**
2. URL: `https://mcp.aisystant.com/mcp`
3. **Add** -> **Connect** -> форма входа Ory -> email и пароль от Aisystant
4. **"Connected to IWE"** -- готово

**Шаг 4 (опционально).** Подключи личные знания через GitHub:
1. Зарегистрируйся на [github.com](https://github.com)
2. Создай репозиторий для заметок (например `My-Knowledge`)
3. Открой [github.com/apps/aisystant-knowledge/installations/new](https://github.com/apps/aisystant-knowledge/installations/new) -> выбери репо -> **Install**
4. Теперь можно искать по своим заметкам и записывать в них из claude.ai

## Что доступно после подключения

| Возможность | Нужен GitHub? | Пример запроса |
|---|---|---|
| Поиск по Pack (методологии, принципы) | Нет | «Что такое системное мышление?» |
| Поиск по курсам и руководствам | Нет | «Как пройти Практики саморазвития?» |
| Цифровой Двойник (профиль, цели) | Нет | «Покажи мой профиль» |
| Поиск по своим заметкам | Да | «Найди мои записи про стратегию» |
| Запись в свои репо | Да | «Запиши инсайт в inbox/» |
| Unified search по всем источникам | Частично | Pack всегда, личные с GitHub |

## Чем отличается от VS Code

| | VS Code (Claude Code) | claude.ai через Gateway |
|---|---|---|
| Полный экзокортекс (файлы, git, протоколы) | да | -- |
| Знания (Pack, курсы, личные) | да | да |
| Запись в GitHub | да (git напрямую) | да (через API) |
| Цифровой Двойник | да | да |
| Локальные файлы и команды | да | -- |
| Мобильный доступ | -- | да |
| Без установки | -- | да |

**Gateway -- это окно в знания**, не замена VS Code. VS Code = полный экзокортекс. Gateway = доступ из любого браузера.

## Для кого

- **Нетехнические участники** -- не нужен VS Code, терминал, git
- **Мобильные сценарии** -- быстрый вопрос к Pack из телефона
- **Мультиплатформенность** -- один IWE, несколько аккаунтов AI-клиентов
- **Демонстрация** -- один URL, вся база знаний
